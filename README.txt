SAFE BROWSING REPORT QUEUE — CLOUDFLARE PAGES

Cara pasang paling cepat:
1. Buka Cloudflare Dashboard > Workers & Pages.
2. Create application > Pages > Upload assets.
3. Upload folder cloudflare-pages atau ZIP-nya.
4. Beri nama proyek dan klik Deploy site.

Tidak memerlukan build command, framework, database, API key, atau backend.
Seluruh antrean hanya disimpan di localStorage browser pengguna.

Catatan: CAPTCHA dan tombol kirim pada Google Safe Browsing tetap manual.
